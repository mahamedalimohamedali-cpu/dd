# CLI Assistant

## Overview
CLI Assistant is a .NET-based desktop productivity suite that leverages Google Gemini AI to streamline content creation, translation, and social media management. It provides a professional interface for automated text processing and direct integration with social platforms.

## Key Features
*   **AI-Powered Translation & Editing:** Offers high-quality English-to-Arabic translation and advanced grammar correction to ensure professional-grade documentation and messaging.
*   **Automated Social Media Publishing:** Generates formatted, engagement-ready Facebook posts from raw descriptions and GitHub links, with direct publishing capabilities via the Facebook Graph API.
*   **Custom Generative Assistant:** Includes a versatile interface for custom AI prompting, allowing users to interact directly with the Gemini-3-Flash model for diverse text-based tasks.

## Technical Stack
*   **Language:** C#
*   **Framework:** .NET / Windows Forms (WinForms)
*   **Integrations:** Google Generative AI (Gemini), Facebook Graph API, HttpClient for RESTful services
